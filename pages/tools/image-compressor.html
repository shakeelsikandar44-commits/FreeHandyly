Image Compressor

Make image files smaller while keeping them looking good. Compare sizes and download instantly.

Image Compressor

Smaller files, same picture

Drop in up to thirty images and each one is re-encoded in your browser with the settings you choose. You see the original size, the new size and the percentage saved for every file, and you can download them separately or as one ZIP. Nothing is uploaded, so it is fine for ID photos, receipts and other things you would rather not send to a stranger's server.

The three settings that matter

Output format. WebP gives the smallest files and is the best default for websites. JPG is the most compatible, which matters when you are sending photos by email or into an older system. PNG is lossless, which is useful for screenshots and graphics with flat colour, but it will not shrink photographs much and the quality slider does not apply to it.

Quality. The default is 75. For most photos anything from 70 to 80 looks fine on screen and cuts the size a lot. Below about 50 you start to see blocky patches around edges and in gradients. Try a middle value, zoom in on a face or a sky, and only go lower if it still looks clean.

Maximum width. This is often the bigger saving. A phone photo can be 4,000 pixels wide, while a blog column displays it at 800 to 1,600. Setting a maximum width to match where the picture will appear removes pixels no one will ever see.

What you can expect

Photos from a modern phone typically shrink by well over half when resized and saved at medium quality. Screenshots saved as PNG often shrink most when converted to WebP. If an image is already well compressed and the new version would not be smaller, the tool keeps your original and tells you, instead of handing back a bigger file.

Smaller images help web pages load faster, which matters for visitors on mobile data and is one of the things search engines measure. They also help when an upload form has a size limit, such as 200 KB for a job application photo. Because the image is re-drawn during compression, details embedded in the file such as GPS location and camera model are dropped, which is a small privacy bonus.

Questions people ask

How much can I reduce an image without losing quality?

For photos, quality 70 to 80 plus a sensible maximum width usually cuts the size by half or more while looking the same on a normal screen.

Which format gives the smallest file?

WebP is normally the smallest. Choose JPG if the file has to open on older software.

Why did the tool keep my original file?

If the compressed version would not have been smaller, the original is kept so you never end up with a bigger file.

Can I compress to an exact size such as 100 KB?

There is no target-size box, but lowering the quality or the maximum width step by step gets you there quickly, and the new size is shown instantly.

Are my images uploaded?

No. All the work happens in your browser.
